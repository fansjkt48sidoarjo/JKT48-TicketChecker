Deploy Apps Script → URL /exec

Tiga momen penting yang akan kamu hadapi di browser (dengan akun Google-mu).
1

Buka editor Apps Script dari spreadsheet

docs.google.com/spreadsheets/d/…
File
Edit
Extensions ▶ Apps Script
Help
// setelah menu Extensions → Apps Script terbuka:
// hapus semua kode, tempel isi google_apps_script.gs,
// lalu tekan Ctrl+S (simpan).
Di jendela spreadsheet: menu Extensions (Ekstensi) → Apps Script. Editor terpisah akan terbuka.
2

Deploy > New deployment dialog kunci

New deployment×
Web app ▾
jkt48-history
Me (akun Google-mu) ▾
Anyone ▾
Setelah klik Deploy, Google akan meminta izin: pilih akun → Advanced → Go to … (unsafe) → Allow. Ini normal untuk skrip milik sendiri.
CancelDeploy

Yang WAJIB benar:

1. Type = Web app (bukan add-on/API)

2. Execute as = Me

3. Who has access = Anyone

Kalau tertulis "Anyone with a Google account", ganti ke Anyone — dashboard memanggil tanpa login.

3

Salin URL Web app berakhiran /exec

script.google.com/macros/s/…/exec
✅ Deployment berhasil.

Web app URL:
https://script.google.com/macros/s/AKfycbw…xxxx/exec

Klik Copy — inilah nilai untuk env var SHEETS_WEBAPP_URL.
URL yang disalin harus diakhiri /exec. Jangan pakai URL /dev (itu versi uji sementara).
4

Verifikasi cepat (opsional tapi disarankan)

# di terminal mana pun:
curl "https://script.google.com/macros/s/XXXXXXXXXX/exec?action=log"
# hasil yang benar → {"entries":[]} (sheet masih kosong)
# kalau dapat HTML/login → cek "Who has access" harus Anyone
Setelah dashboard tersambung dan ada perubahan tiket, buka spreadsheet-nya — sheet "Riwayat" otomatis terisi baris demi baris.
